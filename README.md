
# Java Theatre — практика ООП на Java

Учебное консольное приложение, моделирующее театральные постановки и участников спектаклей. Проект создан для практики **объектно-ориентированного программирования на Java**: наследования, переопределения методов, работы с коллекциями и сравнения объектов.

Это небольшая учебная модель, а не система продажи билетов или полноценная информационная система театра.

## Что умеет программа

- Создаёт обычные представления, оперы и балеты.
- Хранит сведения об актёрах, режиссёрах и других участниках постановок.
- Добавляет актёров в состав постановки, не допуская повторного добавления равного объекта.
- Заменяет актёра по фамилии и сообщает, если он не найден.
- Выводит список актёров и тексты либретто музыкальных постановок в консоль.

В `Theatre.main()` задан демонстрационный сценарий: создаются три постановки, формируются актёрские составы, выполняется замена актёра в опере и выводятся либретто. **Ввода с клавиатуры нет** — данные для демонстрации заданы в коде.

## Технологии

- Java Core (рекомендуется JDK 17 или новее)
- ООП: наследование, переопределение методов, полиморфизм
- `ArrayList` и дженерики
- `equals()` и `hashCode()`
- `enum`
- Текстовые блоки Java (`"""`)

Сторонние библиотеки, Maven, Gradle и база данных не используются.

## Модель классов

```text
Person
├── Actor
└── Director

Show
└── MusicalShow
    ├── Opera
    └── Ballet
```

- **`Person`** — базовые данные человека: имя, фамилия и пол.
- **`Actor`** — актёр с указанием роста; переопределены `equals()`, `hashCode()` и `toString()`.
- **`Director`** — режиссёр с дополнительным полем количества постановок.
- **`Show`** — название, длительность, режиссёр и актёрский состав; методы добавления, замены и вывода актёров.
- **`MusicalShow`** — музыкальная постановка с автором музыки и либретто.
- **`Opera`** — опера с дополнительным полем размера хора.
- **`Ballet`** — балет с указанием хореографа.
- **`Gender`** — перечисление значений пола.

## Как запустить

**Требования:** JDK 17 или новее. Программа проверена компиляцией и запуском на Java 21.

### Через IntelliJ IDEA

1. Склонируйте или скачайте репозиторий.
2. Откройте его в IntelliJ IDEA.
3. Найдите `src/Theatre.java`.
4. Запустите метод `main()` класса `Theatre`.

### Через терминал (Linux/macOS)

Из корневой директории репозитория:

```bash
javac -encoding UTF-8 -d out src/persons/*.java src/shows/*.java src/Theatre.java
java -cp out Theatre
```

Программа выведет составы актёров трёх постановок, обновлённый состав оперы, сообщение о ненайденном актёре в балете и тексты либретто.

## Ограничения и возможные улучшения

- Данные создаются в `main()` и не сохраняются между запусками.
- Нет пользовательского интерфейса, интерактивного ввода или базы данных.
- Автоматических тестов в исходниках нет.
- При замене актёра не проверяется, присутствует ли новый актёр уже в составе.
- Для некоторых полей классов пока не предусмотрены отдельные операции.

Возможные следующие шаги: добавить JUnit-тесты, валидацию данных, более гибкий поиск актёров и разделить демонстрационный сценарий и предметную логику.
